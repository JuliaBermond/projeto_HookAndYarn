# Hook & Yarn — Backend API

## Descrição

API REST construída em **Node.js** com **Express**, responsável pelo gerenciamento de usuários e posts da plataforma HookAndYarn, destinado ao compartilhamento de padrões de crochê criados pelos usuários cadastrados.

A aplicação possui:

- autenticação via **cookies HTTP-only**
- rotas protegidas
- CRUD de posts
- upload de imagens com **Cloudinary**
- persistência de dados com **MongoDB/Mongoose**

Projeto desenvolvido por Julia Bermond para fins educacionais e treinamento em Javascript.

---

## Tecnologias Utilizadas

- Node.js  
- Express.js  
- MongoDB / Mongoose  
- Cookie-based Authentication  
- Bcrypt (hash de senhas)  
- Multer (upload de arquivos)  
- Cloudinary (armazenamento de imagens)  
- JSON Web Token (geração de token)  
- Nodemon (ambiente de desenvolvimento)  
- Dotenv (variáveis de ambiente)  
- CORS  
- Cookie-parser  
- Validator
